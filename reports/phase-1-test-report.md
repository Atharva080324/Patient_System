## 3. UI Click Path & Manual Verification Walkthrough

1. **Doctor Login (`/login`):**
   - Navigate to `http://localhost:3000/login`.
   - Test invalid credentials: enter wrong email/password. Observe generic, non-revealing error message *"Invalid email or password."*
   - Test rate limiting: attempt 5 failed logins; on 6th attempt observe *"Too many login attempts. Please try again in 15 minutes."* (HTTP 429).
   - Enter valid doctor credentials created via `pnpm admin:create`.
   - If 2FA is enabled, observe automatic redirection to `/login/2fa`.

2. **Two-Factor Authentication (`/login/2fa`):**
   - On `/login/2fa`, input the 6-digit TOTP code generated by Google Authenticator / 1Password.
   - Alternatively, click *"Use a single-use recovery code"*, paste a recovery code, and submit.
   - Upon successful verification, the browser receives the secure `__Host-session` cookie and redirects to `/settings/security`.

3. **Security Settings Page (`/settings/security`):**
   - **Password Change:** Enter current password and new 12+ character password. Form validates and updates hash; all other active sessions are revoked.
   - **2FA Setup:** Click *"Setup Two-Factor Authentication"*. Scan the generated QR code in an authenticator app, input confirmation code, and save the 10 displayed single-use recovery codes.
   - **Kiosk PIN Rotation:** Enter current password and new 4–10 digit PIN. Existing kiosk device sessions are immediately revoked.
   - **Sign Out Everywhere:** Click button to instantly revoke all active doctor sessions.
